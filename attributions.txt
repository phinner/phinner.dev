  java.svg          linkedin.svg

Downloaded by the site author 2026-07-28. Neither icon exists in Simple Icons:
both were removed at the trademark holders' request.

Modified in two ways; the path data itself is unchanged:
  - The hard-coded fill attributes were stripped (java carried fill="#000000"
    on the root <svg>, linkedin on the <path>) so the icons inherit the page
    colour via CSS currentColor.
  - Each viewBox was cropped to the artwork's measured bounds so the icons sit
    at the same optical size as the Simple Icons glyphs:
        java      0 0 32 32  ->  6 3 20 26
        linkedin  0 0 24 24  ->  4 4 16 16
